## What it does

<CardGrid>
  <Card title="Merge requests" icon="random">
    List, view, open, and update merge requests — drafts, labels, reviewers, and close or reopen.
    [Reference](/reference/merge-requests/)
  </Card>
  <Card title="Repository files" icon="document">
    Read a file at any ref, and create or replace one with a commit — with a guard against overwriting someone else's
    edit. [Reference](/reference/repository-files/)
  </Card>
  <Card title="Commits and diffs" icon="list-format">
    Walk history, narrow to one path, read a single commit and its diff, or commit several file changes atomically.
    [Reference](/reference/commits/)
  </Card>
  <Card title="Branches, tags, releases" icon="seti:git">
    List and create branches; see the tags and releases a project has. [Reference](/reference/branches-tags/)
  </Card>
  <Card title="CI/CD" icon="rocket">
    Find failed jobs, read the tail of a job log, list variables, and see what is deployed where.
    [Reference](/reference/cicd/)
  </Card>
  <Card title="Search" icon="magnifier">
    Across the instance, a group, or one project — including blob search for finding code.
    [Reference](/reference/search/)
  </Card>
  <Card title="Projects" icon="open-book">
    Find what a token can reach, by name or path, and inspect one. [Reference](/reference/projects/)
  </Card>
  <Card title="MCP server" icon="puzzle">
    The same capabilities for Claude, Cursor, or any MCP client, read-only unless a person opts into writes.
    [Guide](/guides/mcp-server/)
  </Card>
  <Card title="Scripts and agents" icon="setting">
    `--json` returns the raw API payload, exit codes are stable, and a `read_api` token makes writes structurally
    impossible. [Guide](/guides/scripting/)
  </Card>
</CardGrid>

## Install

```sh
npm install -g @simplysf/simply-cli
simply gitlab --help
```

Then point it at your instance with two environment variables — see
[Credentials](/guides/credentials/).

```sh
export GITLAB_TOKEN=glpat-...            # GITLAB_URL defaults to https://gitlab.com
simply gitlab mr list --project group/project
```
